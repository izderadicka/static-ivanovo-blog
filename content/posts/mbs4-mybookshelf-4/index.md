[mbs4 ](https://github.com/izderadicka/mbs4) is basically ready and has same functionality as old [mbs2](https://github.com/izderadicka/mybookshelf2), which I'm finally abandoning - run this 10 years old solution in Docker with ancient dependencies, but enough is enough, mbs4 takes over.




<span id="more-2349"></span>




mbs4 is modern application optimized for selfhosting -  efficient Rust backend with sqlite3 database and modern Svelte 5 client.






As almost everybody in industry I started to do agentic coding -  so mbs4 was finished with help of Codex initially and Claude Code recently.  Speedup was significant on latest features - at least order of magnitude. 






Still learning how to use agents -  this project is now my playground.  Productivity is definitely higher, but have to say it's less fun. Feel more like regular work - you assign work and then check results.
